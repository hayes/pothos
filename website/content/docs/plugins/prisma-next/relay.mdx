Nodes require the [Relay plugin](../relay). See [Connections](./connections) for pagination.

## Define a node

`builder.prismaNode` takes the same options as `builder.prismaObject`, plus an `id`:

```ts
builder.prismaNode('Post', {
  id: { field: 'id' },
  fields: (t) => ({
    title: t.exposeString('title'),
    author: t.relation('author'),
  }),
});
```

- `id.field`: a column, or a list of columns, covering a non-null primary or unique key.
- `id.parse` / `id.resolve`: custom ID serialization. `resolve` requires `parse`.
- Other `id` options, such as `description`, are passed to the ID field.
- `collection`: the Collection nodes load from. See [Filter node lookups](#filter-node-lookups).

```ts
builder.prismaNode('Comment', {
  id: {
    field: 'id',
    resolve: (comment) => `comment:${comment.id}`,
    parse: (id) => id.slice('comment:'.length),
  },
  fields: (t) => ({ body: t.exposeString('body') }),
});
```

`node` and `nodes` lookups of one type are batched into one query.

On PostgreSQL, a timestamp ID column read as a JavaScript `Date` must have a precision of 3 or
less (bare `DateTime` is fine). Use `TimestamptzTemporal` for finer timestamps.

## Filter node lookups

`collection` is a function of the context, so it can filter by the request:

```ts
builder.prismaNode('Post', {
  id: { field: 'id' },
  collection: (ctx) => ctx.db.orm.Post.where({ authorId: ctx.viewerId }),
  fields: (t) => ({ title: t.exposeString('title') }),
});
```

`node` and `nodes` return `null` for rows the filter excludes. Only filter the collection; don't
call `limit()`, `offset()`, `cursor()` or `include()` on it.

`collection` only applies to `node` and `nodes`; rows reached through relations and other fields
don't pass through it. Neither it nor a function `client` is access control, so restrict rows with
auth checks on the type.

## Several node types for one model

Each node type has its own global IDs. Where one field can return several of them, return a
[`prismaInterface`](./interfaces) with a `resolveType`, or brand each row with its type's
`addBrand`:

```ts
const DraftPost = builder.prismaNode('Post', {
  variant: 'DraftPost',
  id: { field: 'id' },
  fields: (t) => ({ title: t.exposeString('title') }),
});

builder.queryField('latestDraft', (t) =>
  t.field({
    type: builder.nodeInterfaceRef(),
    nullable: true,
    resolve: async (_root, _args, ctx) => {
      const post = await ctx.db.orm.Post.where({ published: 0 }).first();
      return post && DraftPost.addBrand(post);
    },
  }),
);
```
