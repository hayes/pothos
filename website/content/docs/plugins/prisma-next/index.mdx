<Callout type="warn" title="Experimental">
  This plugin targets Prisma ORM `8.0.0-rc.22` exactly. Its API, and Prisma's, may change in any
  release.
</Callout>

The Prisma Next plugin defines GraphQL types from the models in a
[Prisma ORM 8](https://github.com/prisma/orm) contract and adds the selections each query needs to
the Collections your resolvers return. It supports relations, counts, variants, interfaces, and
Relay nodes and connections.

For Prisma ORM 7, use [`@pothos/plugin-prisma`](/docs/plugins/prisma) instead. The two can't be used
together.

The [playground example](/playground?example=plugin-prisma-next) runs the examples below against
SQLite in the browser, and its **SQL** tab shows the statements each query runs.

## Example

A `User` type with a computed name and a filtered relation:

<include cwd lang="typescript" meta='playground example="plugin-prisma-next"'>playground-examples/plugin-prisma-next/types/user.ts#user</include>

A root field returns an unexecuted Collection:

<include cwd lang="typescript" meta='playground example="plugin-prisma-next" query="{ users { fullName posts { title author { email } } } }"'>playground-examples/plugin-prisma-next/queries.ts#users-query</include>

This query loads the users, their posts, and each post's author in one Collection call:

```graphql
query {
  users {
    fullName
    posts {
      title
      author {
        email
      }
    }
  }
}
```
