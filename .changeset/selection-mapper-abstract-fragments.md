---
'@pothos/selection-mapper': minor
---

- Plan fields in a fragment on an abstract type with no model (`... on Node` beneath a model interface), or of another model, for each implementation it covers, instead of leaving them to the fallback. The parent query then carries those variants' type-level selects, and a variant with no type-level select widens it to the whole row. Every such fragment is left unexpanded if those selects conflict with each other, with another variant the document enters, or with the initial selection, or if one of them conflicts with a field-level select elsewhere in the query and every field the fragment expands to has a select of its own. A field with a select of its own then loads separately. When those selects conflict with each other, a field with none reads the row as loaded, so a column only the variant's type-level select would have loaded is `undefined`, with no error. When a variant only conflicts with a field-level select and the fragment holds a field with no select, the fragment stays expanded and the field-level select reloads per row.
- A field reached on several types by such a fragment shares the walk beneath it, and so does every field whose selection set is written the same way, under any field of the same root plan (a named fragment spread beneath several fields at every level), so planning stays linear in the document's depth. Reading `Position.parent` during planning keeps the walks it reads through from being shared, so each sees its true path, at the old cost for those walks; a walk with an async select function is not shared either. `Position.walkParent` reads the shared walk's chain without that cost, for a name that only has to agree with itself.
- `deepEqual` no longer throws on Temporal values. Instances with no enumerable state compare through their `equals`, or by identity when they have none (`Map`, `Set`, `RegExp`, Prisma's null types). Typed arrays compare by type and bytes.
- `Plan.forParentRow` takes an options object: `forParentRow(adapter, { context, info, skipDeferredFragments, initial })` replaces `forParentRow(adapter, context, info, skipDeferredFragments)`. The `Mapping` and `ParentRowOptions` types are exported.
